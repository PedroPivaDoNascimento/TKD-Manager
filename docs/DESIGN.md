# Sistema de Design (UI/UX) - TKD Manager

**Identidade Visual Oficial – Baseada no Centro de Treinamento Miguetti Team**

---

## 1. Princípios de Interface & Identidade
* **Estética Marcial de Alto Contraste:** Inspirada no brasão oficial da academia, combinando superfícies escuras (`#111111`) ou fundos claros limpos (`#F4F5F7`) com acentos fortes em **Vermelho Carmesim** (`#D91A1A`) e **Prata Metálico** (`#C4C9D4`), transmitindo *Sabedoria, Disciplina e Honra*.
* **Foco Operacional:** Interface otimizada para o professor visualizar rapidamente métricas gerenciais e realizar operações na beira do tatame.

---

## 2. Paleta de Cores Oficial (Extraída da Logo)

| Token / Papel | Cor / Hex | Aplicação na Interface |
| :--- | :--- | :--- |
| **Primária (Vermelho Miguetti)** | `#D91A1A` | Botões principais (CTA), barras de destaque em gráficos, ícones e bordas ativas |
| **Primária Hover** | `#B01212` | Estado de hover em botões |
| **Secundária / Dark (Preto Tatame)** | `#111111` | Sidebar, Navbar e elementos de destaque escuro |
| **Superfície Principal (Claro)** | `#F4F5F7` | Fundo geral do painel administrativo |
| **Superfície Card** | `#FFFFFF` | Cards de métricas, tabelas analíticas e gráficos |
| **Borda Metálica (Prata)** | `#C4C9D4` | Contornos de cards, gráficos e divisórias |
| **Sucesso / Alerta / Erro** | `#16A34A` / `#F59E0B` / `#DC2626` | Status de mensalidades e indicadores |
| **Ação WhatsApp** | `#25D366` | Botão de disparo rápido de cobrança |

---

## 3. Componentes do Dashboard Analítico
* **Cards de Indicadores (KPIs):** Exibição em destaque do total geral de alunos ativos.
* **Tabela e Gráfico de Matrículas:** Componentes visuais limpos exibindo quem foi o responsável por captar cada matrícula, permitindo ao professor auditar o volume de conversão de forma prática.
* **Badges de Graduação:** Cores correspondentes às faixas de Taekwondo para identificação rápida nas tabelas de alunos.
